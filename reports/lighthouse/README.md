# Relatórios Lighthouse

Esta pasta é o destino versionado dos relatórios gerados por `npm run lighthouse`.

O comando executa 3 medições por combinação de página/perfil, preserva HTML/JSON de cada execução e grava `ambiente.json` e o resumo da mediana.

Os relatórios empíricos não são fabricados nem preenchidos manualmente: devem ser produzidos pelo script em um ambiente com as dependências instaladas e então versionados junto da entrega.
